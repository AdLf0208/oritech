# Oritech slice 1 — content carry

`assets/` and `data/` at the package root are generated by
[`tools/carry_content.py`](tools/carry_content.py) from the ATM10 jar
`oritech-neoforge-1.21.1-1.2.13.jar`
(SHA-256 `32600bf5b08fcf6d4a49e557f90ee45b238098170777872c8919d9fdb0a1b828`).
The script is deterministic (`--check` exits 1 on any drift) and writes **25
files** (11 assets, 14 data) at the root; since 0.2.0 they travel in the same
SDK package as `src/`, so there is no separate content `.hmod` and no manifest
here (the root `horizon-mod.toml` is the only one).

not carried here; they are a later slice (see `notes.md`, gaps).

## Deviations from the jar's data

1. **The block models.** The jar's blockstates point at
   `oritech:block/machine_speed_addon` (a placeholder: GeckoLib draws the real
   machine from `assets/oritech/geo/block/models/*.geo.json`, which the pin
   cannot render). This slice maps each machine's **own texture** onto a
   `cube_all`, so the block is visible and distinct without a GeckoLib renderer.
   The models and the machine's block item are what look different; the block's
   collision, hardness, resistance, sounds and tool are the jar's.
2. **No `facing` state.** Upstream's machine blocks carry
   `HORIZONTAL_FACING`; this slice declares no state property, because nothing
   renders or uses the orientation here (every face accepts items and energy).
3. **Loot shape.** Upstream's 1.21.1 `conditions: [ … ]` array evaluates false
   at this pin; the carried loot uses 26.3's `condition: { … }` object. Same
   entry, same `survives_explosion` rule.
4. **No crafting recipes for the two blocks.** The jar's recipes need
   `oritech:motor`, `oritech:magnetic_coil` and the `c:ingots/nickel`,
   `c:storage_blocks/copper` and `c:player_workstations/furnaces` tags, none of
   which exist in this slice or in 26.3's vanilla data. Shipping them would ship
   recipes that can never match, so they are recorded as a gap instead.
5. **The creative tab is the machines tab only.** The jar registers four
   (`itemgroup.oritech.machines|components|decorative|equipment`); this slice has
   items for one.
